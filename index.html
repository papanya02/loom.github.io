What NEXUS adds

Noise gives you a secure channel. NEXUS turns it into a practical runtime for applications.

🔑

Stable identity

Ed25519 root key → durable nx2… Peer ID. Noise session keys can rotate without changing who you are.

📜

Root-signed certs

After Noise XX finishes, peers exchange certificates inside the encrypted channel that bind root identity to the Noise static key.

🤝

Capabilities

Typed offers (id + version). Exact intersection. Base capability nexus/base@2 is mandatory.

🛤️

Path & transport

Intent-aware planner. TCP is implemented today; the seam is ready for QUIC, local mesh and relays.

Noise vs NEXUS

Different layers. Complementary, not competing.

🔐 Noise

Cryptographic foundation. Secure session (Noise XX + ChaChaPoly + BLAKE2s). Encryption, forward secrecy, key confirmation. Used by WireGuard, WhatsApp, Lightning and many others.

noiseprotocol.org →

⚡ NEXUS

Application runtime on top of Noise. Stable identity, root-signed certificates, Peer ID pinning, capability negotiation and transport selection.
