Quick start

Getting Started

Build the binary, generate identities and run a full authenticated exchange on localhost.

Requirements

Rust 1.85+ · Cargo · Windows / Linux / macOS

Install from rustup.rs

Build & test

cargo fmt
cargo test
cargo build --release
cargo clippy --all-targets --all-features -- -D warnings

CLI reference

All commands defined in cli.rs via clap.

CommandDescription
nexus --help / -h Show help for the program or a subcommand
nexus --version / -V Print NEXUS version
nexus keygen --key PATH Generate identity (Ed25519 root + Noise X25519). Refuses overwrite
nexus id --key PATH Print stable Peer ID (nx2…)
nexus transports List implemented (tcp) and planned transports
nexus listen --key PATH --allow-peer-id ID [--bind ADDR] Accept one authenticated connection (default 127.0.0.1:7000)
nexus send --key PATH --peer ADDR --peer-id ID --message TEXT [--intent …] Connect, authenticate, negotiate and send one encrypted message

--intent values

ValueDescription
balancedDefault trade-off (default)
low-latencyPrefer lowest estimated latency
privacy-preferredPrefer highest privacy score
reliablePrefer highest reliability score

Only TCP is available today — all intents still select TCP.

Local test

Three steps · two terminals

1 · Generate identities

cargo run --release -- keygen --key data/alice.json
cargo run --release -- keygen --key data/bob.json
cargo run --release -- id --key data/alice.json
cargo run --release -- id --key data/bob.json

2 · Start Bob (listener)

cargo run --release -- listen \
  --key data/bob.json \
  --bind 127.0.0.1:7000 \
  --allow-peer-id ALICE_NX2_ID

3 · Alice sends

cargo run --release -- send \
  --key data/alice.json \
  --peer 127.0.0.1:7000 \
  --peer-id BOB_NX2_ID \
  --message "Hello from NEXUS 0.2" \
  --intent balanced

Expected flow: TCP → Noise XX → encrypted certificates → Peer ID pin → capabilities → data + ACK

Security notice

This is an engineering prototype, not production infrastructure. Do not use it for custody, financial operations or sensitive communication. Do not expose the listener to the public Internet. Private keys live in plaintext JSON.
